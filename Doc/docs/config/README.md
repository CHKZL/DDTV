# 配置文件说明

DDTV 启动后会将工作目录强制切换为**程序（exe）所在目录**，所有配置文件都保存在程序目录下的 `./Config/` 文件夹中（例如 Windows 发布包中与 exe 同级的 `Config` 文件夹）。

## 当前存在的配置文件列表

| 文件名 | 功能 | 是否可手动编辑 |
|:--:|:--:|:--:|
| `DDTV_Config.ini` | DDTV 通用配置文件（端口、录制、通知等全部设置） | ✔️（需关闭程序后编辑） |
| `RoomListConfig.json` | 监控房间列表及每个房间的独立设置 | ✔️（需关闭程序后编辑） |
| `BiliUser.ini` 及 `.Duser` 文件 | 扫码登录的 B 站账号凭据本地加密缓存（通过本地密钥加密，纯本地保存） | ✖️ |

::: warning 手动编辑注意事项
DDTV 运行期间会每 3 秒自动保存配置文件并**全量覆写**，且文件只在启动时读取一次。手动编辑前请先完全关闭 DDTV，修改并校验格式后再启动；更推荐通过 WEBUI 设置页或 API 修改，立即生效且不易出错。
:::
