# 观看时长心跳

观看时长心跳是指你用 DDTV 桌面版（Desktop）的 **VLC 播放窗口**观看直播时，DDTV 会以你已登录的 B 站账号向 B 站定期发送"正在观看"心跳，从而正常累计观看时长——这是粉丝勋章亲密度结算的依据。适合平时直接用 DDTV 看直播、又不想落下粉丝牌亲密度的用户。

## 这是什么

在网页或官方客户端看直播时，B 站会通过心跳机制统计你的观看时长。用第三方播放器看直播时这个过程不会发生，看再久也不涨亲密度。开启本功能后，DDTV 会在你观看期间模拟这个过程：按 B 站服务器给出的间隔持续发送心跳，直到你关闭播放窗口或主播下播。

## 怎么开启

配置文件 `./Config/DDTV_Config.ini`（也可在 Desktop 设置页中修改）：

| 配置项 | 默认值 | 说明 |
|:--|:--:|:--|
| `PlayWindowWatchHeartbeat` | `false` | VLC 播放窗口观看心跳开关 |

开启后无需其他操作：打开 VLC 播放窗口观看时自动开始发送心跳，关闭窗口自动停止。

## 使用条件与注意事项

::: warning
* **仅 Desktop 的 VLC 播放窗口生效**。WebPlayWindow（内置网页播放窗口）本身就走网页播放器逻辑，不支持也不需要本功能。
* **必须已在 DDTV 中登录 B 站账号**，未登录或登录态失效时心跳不会启动；观看中登录态失效会自动停止。
* 主播下播时心跳自动停止。
* 同一个房间开了多个 VLC 窗口时，共享同一条心跳会话（不会重复发送），最后一个窗口关闭时才停止。
* 如果 B 站接口持续返回失败（如协议变更、登录态问题），连续失败 3 次后会自动放弃，避免无限重试刷请求；具体情况可看日志中 `WatchHeartbeatManager` 相关的记录。
* 心跳发送间隔由 B 站服务器返回决定（通常 60 秒左右），流量开销极小。
:::
