## 当前有单独文档的功能
|功能名称|功能描述|
|:--:|:--|
|[弹幕录制](./弹幕录制.md)|自动录制时同步保存弹幕、礼物、舰队、SC文件，时间轴与视频对齐|
|[自动切割](./自动切割.md)|按文件大小/录制时长/标题变更等条件把一场直播切成多个文件|
|[时间轴修复](./时间轴修复.md)|录制完成后自动修复时间轴并转封装为可正常拖动的MP4文件|
|[文件合并](./文件合并.md)|说明断流重连的文件处理行为，以及手动合并多个分段的方法|
|[自动转码](./自动转码.md)|自定义ffmpeg参数，录制完成后自动转码为需要的格式/编码|
|[邮件通知](./邮件通知.md)|开播提醒、录制结束、修复/转码失败、登录失效时发送邮件提醒|
|[WebHook](./WebHook.md)|把运行状态推送消息实时POST到你指定的HTTP地址|
|[房间Shell命令](./房间Shell命令.md)|（仅Linux）录制完成后自动执行自定义Shell脚本|
|[观看时长心跳](./观看时长心跳.md)|用VLC播放窗口看直播时向B站发送观看心跳，累计观看时长/粉丝牌亲密度|
|[Debug模式](./Debug模式.md)|调试日志开关与Debug快照打包，用于向开发者反馈问题|
|[API服务](./API.md)|方便二次开发，详情请查看`API`页面的API文档|
|[WebSocket服务器](./WebSocket服务器.md)|通过WebSocket实时接收DDTV运行状态推送|
|[WEB服务器](./WEB服务器.md)|内置WEB服务与WEBUI相关配置|

### 以下是部分已经完成的功能，更多功能欢迎下载体验，欢迎提出还未解锁的新功能~
* 录制功能跨平台支持！Windows、MacOS、Linux随意选！
* DDTV初次启动引导窗口
* 多路直播监控，可自定义监听房间，摸鱼中\直播中一目了然
* 多窗口随意排列
* 播放窗口无边框，勿扰模式
* 播放窗口GPU硬解
* 窗口一键自动排列
* 每路声音可单独调整
* 手动录像/开播自动录像
* 高完成度的断线自动重连(就算你拔网线再插上都可以续！)
* 断流重连续录时追加写入同一文件，不会产生零散的碎片文件
* 支持录制\合并完成自动转码为MP4文件为剪切提供友好支持
* 完善的弹幕\SC\舰队\礼物信息录制功能不让你错过任何一个瞬间
* 监控列表开播提示
* 在滑动鼠标滚轮修改窗口音量
* 缩小到系统托盘后台监听
* 更符合原版弹幕飘动显示的样式，拒绝丑陋的单独弹幕窗口，并且占用更低！更流畅！的弹幕显示功能
* 开播,录像气泡提示
* 多路异步下载
* 扫码登陆功能
* 登陆后阿B关注列表VTB\VUP一键自动导入
* 登陆买票后可以观看付费直播内容
* 直播弹幕发送
* 支持弹幕发送、备线切换、清晰度切换、等除送礼外的所有原生直播间功能
* 录制完成后自动修复时间轴并转码为MP4
* 支持按大小/按时长/按标题变更自动切割录制文件
* DDTV本体自动更新
* 跨平台服务端提供友好的WEB信息页
