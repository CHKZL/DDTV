# 邮件通知

邮件通知功能让 DDTV 在发生特定事件（开播提醒、录制结束、修复/转码失败、登录失效）时，通过 SMTP 给你发一封邮件。适合 DDTV 跑在服务器/NAS 上、不方便盯界面，希望"出事才收到提醒"的用户。

## 支持哪些提醒

| 事件 | 对应开关配置项 | 触发时机 |
|:--|:--|:--|
| 开播提醒 | `Email_StartLive_Enable` | 设置了"开播提醒"（IsRemind）的主播开播时 |
| 录制结束 | `Email_RecEnd_Enable` | 房间的录制任务完整结束时 |
| 修复/转码失败 | `Email_TranscodingFail_Enable` | 录制后修复或转码任务失败时（邮件含详细错误）；修复结果异常放弃删除源文件时也会通过此开关提醒 |
| 登录失效 | `Email_LoginFailureReminder_Enable` | 检测到 B 站登录态可能失效时 |

以上开关默认值均为 `false`，需要哪个开哪个。

## 怎么配置

所有配置项都在配置文件 `./Config/DDTV_Config.ini`（也可在 Desktop 设置页 / WEBUI 设置中修改）：

| 配置项 | 默认值 | 说明 |
|:--|:--:|:--|
| `Email_EnableSmtp` | `false` | SMTP 邮件服务总开关 |
| `Email_SmtpServer` | 空 | SMTP 服务器地址，如 `smtp.qq.com` |
| `Email_SmtpPort` | `25` | SMTP 端口 |
| `Email_SmtpSecurity` | `auto` | 加密方式：`auto`（自动判断）/ `none`（不加密）/ `tls`（连接即 TLS，常用于 465）/ `starttls`（先明文再升级，常用于 587）/ `opportunistic`（服务器支持才加密） |
| `Email_SmtpUserName` | 空 | SMTP 登录用户名，一般就是你的邮箱地址 |
| `Email_SmtpPassword` | 空 | SMTP 密码，**多数邮箱这里要填"授权码"而不是登录密码**（见下） |
| `Email_SmtpFrom` | 空 | 发件人邮箱地址 |
| `Email_SmtpFromName` | `DDTV` | 发件人显示名 |
| `Email_SmtpTo` | 空 | 收件人邮箱地址（接收提醒的邮箱） |

## 配置示例

::: warning 关于"授权码"
QQ 邮箱、163 邮箱等国内邮箱**不允许直接用登录密码调 SMTP**，需要先在邮箱网页版的设置里开启 SMTP 服务，开启后会生成一串"授权码"（也叫"独立密码"），把授权码填到 `Email_SmtpPassword` 里。
:::

### QQ 邮箱

QQ 邮箱设置路径：网页版 QQ 邮箱 → 设置 → 账号 → 开启"POP3/SMTP服务"，按提示验证后获得授权码。

```ini
Email_EnableSmtp = true
Email_SmtpServer = smtp.qq.com
Email_SmtpPort = 465
Email_SmtpSecurity = tls
Email_SmtpUserName = 123456789@qq.com
Email_SmtpPassword = 你的授权码
Email_SmtpFrom = 123456789@qq.com
Email_SmtpFromName = DDTV
Email_SmtpTo = 接收提醒的邮箱@xxx.com
```

### 163 邮箱

163 邮箱设置路径：网页版 163 邮箱 → 设置 → POP3/SMTP/IMAP → 开启 SMTP 服务并获得授权码。

```ini
Email_EnableSmtp = true
Email_SmtpServer = smtp.163.com
Email_SmtpPort = 465
Email_SmtpSecurity = tls
Email_SmtpUserName = yourname@163.com
Email_SmtpPassword = 你的授权码
Email_SmtpFrom = yourname@163.com
Email_SmtpFromName = DDTV
Email_SmtpTo = 接收提醒的邮箱@xxx.com
```

::: tip
* `Email_SmtpFrom` 一般要和 `Email_SmtpUserName` 一致（自己发给自己最不容易被拦），`Email_SmtpTo` 可以填另一个常用邮箱。
* 发信失败会在 DDTV 日志中记录一条 Warn 级别的失败原因（如认证失败、连接超时），配置后建议先触发一次测试（如给某个房间开开播提醒）确认能收到。
* 邮件正文为 HTML 格式，标题为事件类型（如"开播提醒"、"修复或转码失败"），正文中包含房间名、房间号和错误详情。
:::
