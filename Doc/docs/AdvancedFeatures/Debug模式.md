# Debug模式

Debug 模式用于在排查问题时输出更详细的调试日志，并可以把配置和日志打包成"Debug 快照"文件发给开发者分析。普通用户平时无需开启，遇到灵异问题、需要向开发者反馈时再用。

## Debug 模式开关

配置文件 `./Config/DDTV_Config.ini`：

| 配置项 | 默认值 | 说明 |
|:--|:--:|:--|
| `DebugMode` | `false` | 调试模式开关。只控制 Debug 级别的日志是否显示/记录，不影响任何录制功能 |

也可以在 Desktop 设置页 / WEBUI 设置中修改。

### Server 版控制台热切换

Server 模式下不用改配置、不用重启：在控制台按 `i` 进入交互菜单后，按 `z` 即可在"打开/关闭调试模式"之间切换，立即生效。

## Debug 快照（给开发者的一键打包）

Debug 快照会把 `./Config/` 目录下的配置和日志数据库打包成 zip，并用内置公钥加密（AES+RSA），生成到 `./Debug/` 目录，文件名形如 `Debug_2026-08-06T12-00-00-000.zip_Encryof.zip`。因为文件被加密，只有开发者能解开，所以你不用担心配置里的敏感信息（如账号凭据）在传输中泄露——但也意味着这个文件你自己打不开，它是专门用来发给开发者排查问题的。

生成方式（任选其一）：

* **Server 控制台**：按 `i` 进入菜单后按 `d`（生成调试包）
* **Desktop**：设置页中的"生成 Debug 快照"相关按钮
* **API**：调用 `system/generate_debug_file_snapshot` 接口，返回生成文件的路径

生成后把 `./Debug/` 下的 `_Encryof.zip` 文件发给开发者（可在 DDTV 功能反馈讨论群 `338182356` 联系），并附上问题现象和大致时间点即可。

::: tip
开启 `DebugMode` 后再重现一遍问题、然后生成快照，日志信息量最大，排查效率最高。排查完记得关掉 Debug 模式，避免日志量过大。
:::
